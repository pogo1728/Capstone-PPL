# Mental Health Analysis System

A Python-based data analysis project that explores the prevalence of mental health disorders across different countries and over multiple years.

The project analyses five mental health disorders:
- Schizophrenia
- Depression
- Anxiety
- Bipolar Disorder
- Eating Disorder

### Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

### Repository Files
- `Code.py` – Python implementation of the project.
- `File.csv` – Dataset used for analysis.
